# Security Policy

## Supported Versions

A supported-version policy has not yet been established. The current package version is recorded in `package.json`; its presence does not imply a support commitment.

## Reporting a Vulnerability

TriType Arena is a local-first, client-side browser application with zero backend or telemetry endpoints. However, if you discover any security issue (e.g. DOM XSS, prototype pollution, malicious dependency, or accidental credential leak):

1. Please do **NOT** disclose the issue publicly in an open GitHub issue.
2. Report the vulnerability privately via GitHub Security Advisories or to the maintainers.
3. Include reproducible steps and proof-of-concept payload if applicable.
4. Maintainers can review the report and coordinate remediation; no response time is currently guaranteed.
