# Browser smoke test
`python3 scripts/browser-smoke.py` requires Python Playwright and a system Chromium at `/usr/bin/chromium` (the present evaluation environment). It loads the browser UI from `page.set_content` plus ES-module data URL to bypass restricted localhost navigation; verifies initial render and Pinyin/Zhuyin completion. For normal development migrate the test to `tests/e2e/*.spec.ts`, use Playwright's HTTP server fixture and test against the deployed Vite app.

# Vocabulary release gate
`npm run build:release` checks the vocabulary source register before building; it fails while any of the three current batches is not explicitly cleared for public release. `npm run build` remains available for local development and build verification. The draft Pages workflow and repository Vercel build configuration use the release command. Verify the actual Vercel project settings and deployment path before relying on this gate: dashboard overrides, other build commands or services may bypass it. It cannot retract existing deployments, prevent repository visibility changes, or verify copyright evidence; clearance requires human review. A replacement dataset with different batches also requires updating the gate and provenance validation.
