# Proposal — tri-language typing MVP
## Problem
Standard typing apps disproportionately focus on English, and Chinese typing tends to mix phonetic keys with IME output, creating incorrect comparable metrics. Provide an enjoyable, transparent, local-first typing trainer.
## Goal
Deliver 3 input modes, 3 durations, live stats, local best, and a testable core without login.
## Out of scope
Online multiplayer; external language corpus; speech; full IME conversion; cross-language WPM ranking.
## Risks
Standard Zhuyin key mapping differences and browser IME; WPM interpretation; repeated words creating memorization bias; user accessibility. Mitigation: default Daqian label, key mapping tests, explain scoring, stage external lessons.
