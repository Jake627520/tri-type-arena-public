# Specification — License & Secret Compliance

## LC-001 License Attribution
All code authored in the repository SHALL be licensed under the MIT License.

## LC-002 Cleanroom & Copyleft Prohibition
No source code, assets, audio, or dictionaries from GPL/AGPL licensed typing projects SHALL be imported or copied.

## LC-003 Secret Scanning
No private keys, OAuth tokens, API secrets, or credentials SHALL be committed to Git.
