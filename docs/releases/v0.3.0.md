TriType Arena is a free, offline-first typing practice game supporting English, Simplified Chinese Pinyin, and Traditional Chinese Zhuyin.

## What's New
- **Multilingual Interface:** Traditional Chinese (zh-TW), Simplified Chinese (zh-CN), and English.
- **Beginner Onboarding:** A three-step interactive guide for new users.
- **Language Preferences:** Automatically detects browser language and remembers user preferences.
- **Typing Modes:** English keyboard, Hanyu Pinyin, and Traditional Chinese Zhuyin (Daqian layout).
- **Accessibility:** Improved keyboard navigation, focus management, and localized UI controls.

## Quality & Security
- 120 automated tests passed.
- TypeScript, ESLint, and production build verified.
- 0 known dependency vulnerabilities reported at release validation.
- License and secret scanning completed successfully.

## Notes
- No user account or sign-in is required.
- The game runs locally in your browser.
- No cloud synchronization or online multiplayer is included in this release.
- This is an early release intended for continued development and improvement.
